# Tarea 3 — Red Social Estudiantil Pascualina

## Descripción
Este repositorio contiene la implementación del modelo físico de la base de datos de la Red Social Estudiantil Pascualina, desarrollada como parte de la asignatura de Bases de Datos.

## Contenido del repositorio
- `modelo_fisico.sql`: script DDL para crear la estructura de la base de datos.
- `informe/`: informe técnico con la justificación del SGBD, la descripción de las tablas y las relaciones, y las conclusiones individuales.
- `video/`: enlace al video de sustentación del proyecto.

## Sistema gestor de bases de datos
PostgreSQL.
